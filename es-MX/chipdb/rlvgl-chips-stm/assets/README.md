# Activos de la base de datos de chips STM

Este directorio almacena la base de datos de chips STM comprimida. El archivo
`chipdb.bin.zst` se genera ejecutando `scripts/stm32_afdb_pipeline.sh`
y no se incluye en el control de versiones.
