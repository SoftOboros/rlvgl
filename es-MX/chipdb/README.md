Crates que incrustan datos de chips y placas específicos del proveedor para rlvgl-creator.

- [rlvgl-chips-microchip](./rlvgl-chips-microchip/README.md) – Base de datos de chips de Microchip.

- [rlvgl-chips-renesas](./rlvgl-chips-renesas/README.md) – Base de datos de chips de Renesas.
- [rlvgl-chips-rp2040](./rlvgl-chips-rp2040/README.md) – Base de datos de chips RP2040.
- [rlvgl-chips-silabs](./rlvgl-chips-silabs/README.md) – Base de datos de chips de Silicon Labs.
- [rlvgl-chips-stm](./rlvgl-chips-stm/README.md) – Base de datos de chips de STMicroelectronics.
- [rlvgl-chips-ti](./rlvgl-chips-ti/README.md) – Base de datos de chips de Texas Instruments.
