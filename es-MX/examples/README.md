# Ejemplos

Proyectos de ejemplo que demuestran rlvgl en diferentes entornos.

- [Simulador de escritorio](./sim/README.md) – Ejecuta rlvgl en un sistema anfitrión.
- [STM32H747I-DISCO](./stm32h747i-disco/README.md) – Demostración bare-metal para la placa STM32H747I-DISCO.
- [STM32F429I-DISCO](./stm32f429i-disco/README.md) – Demostración bare-metal que destaca la generación de BSP consciente del bus en un MCU F4.
- [STM32L476G-DISCO](./stm32l476g-disco/README.md) – Ejemplo de BSP consciente del bus para la placa L4 Discovery.
- [STM32F746G-DISCO](./stm32f746g-disco/README.md) – Demostración de BSP consciente del bus para una placa F7 Discovery.
- [STM32F769I-DISCO](./stm32f769i-disco/README.md) – Demostración de BSP consciente del bus para una placa F7 Discovery con limpieza de BDMA/MDMA.
- [STM32H573I-DISCO](./stm32h573i-disco/README.md) – Demostración de BSP consciente del bus que muestra el soporte H5.
- [STM32U599I-EVAL](./stm32u599i-eval/README.md) – Demostración de BSP consciente del bus que destaca los periféricos U5.

Directorios adicionales como `assets-pack` y `common_demo` proporcionan activos compartidos y código auxiliar.
