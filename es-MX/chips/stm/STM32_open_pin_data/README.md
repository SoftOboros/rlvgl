# STM32_open_pin_data

Este repositorio proporciona toda la información requerida para la **configuración de pines** de productos basados en MCUs STM32.
Se proporciona como una conveniencia para la generación de configuración de pines en proyectos que no dependen de **STM32Cube** o **STM32CubeMx** para este propósito.
Los archivos proporcionados son un subconjunto de la base de datos interna de STM32CubeMx. Se actualizan con cada nueva versión de STM32CubeMx.
Como consecuencia, este repositorio no está abierto a contribuciones de usuarios, pero cualquier problema reportado será atendido.
