# STM32_open_pin_data

Ce dépôt fournit toutes les informations requises pour la **configuration des broches** des produits basés sur les microcontrôleurs STM32.
Il est fourni à titre de commodité pour la génération de la configuration des broches dans les projets qui ne dépendent pas de **STM32Cube** ou **STM32CubeMx** à cette fin.
Les fichiers fournis sont un sous-ensemble de la base de données interne de STM32CubeMx. Ils sont mis à jour avec chaque nouvelle version de STM32CubeMx.
Par conséquent, ce dépôt n'est pas ouvert aux contributions des utilisateurs, mais tout problème signalé sera traité.
