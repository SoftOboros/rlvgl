# Bases de données de puces de fournisseurs

Crates qui intègrent les données de puces et de cartes spécifiques aux fournisseurs pour rlvgl-creator.

## Crates
- [rlvgl-chips-esp](./rlvgl-chips-esp/README.md) – Base de données de puces Espressif.
- [rlvgl-chips-microchip](./rlvgl-chips-microchip/README.md) – Base de données de puces Microchip.
- [rlvgl-chips-nrf](./rlvgl-chips-nrf/README.md) – Base de données de puces Nordic.
- [rlvgl-chips-nxp](./rlvgl-chips-nxp/README.md) – Base de données de puces NXP.
- [rlvgl-chips-renesas](./rlvgl-chips-renesas/README.md) – Base de données de puces Renesas.
- [rlvgl-chips-rp2040](./rlvgl-chips-rp2040/README.md) – Base de données de puces RP2040.
- [rlvgl-chips-silabs](./rlvgl-chips-silabs/README.md) – Base de données de puces Silicon Labs.
- [rlvgl-chips-stm](./rlvgl-chips-stm/README.md) – Base de données de puces STMicroelectronics.
- [rlvgl-chips-ti](./rlvgl-chips-ti/README.md) – Base de données de puces Texas Instruments.
