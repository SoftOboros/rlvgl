# STM32_open_pin_data

This repo provides all the information required for the **pin configuration** of products based on STM32 MCUs.
It is provided as a convenience for pin configuration generation in projects that do not rely on **STM32Cube** or **STM32CubeMx** for this purpose.
The files provided are a subset of the STM32CubeMx internal database. They are updated with each new STM32CubeMx version.
As a consequence, this repo is not open to user contributions, but any issues reported will be addressed.
