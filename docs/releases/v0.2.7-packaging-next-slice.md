## Real-crate experiment

Unlike the earlier synthetic fixture, this experiment uses the current
candidate's actual API, core and platform inventory, outside the live workspace.
Cargo `package --list` determines each payload file set. The prototype copies
those files, strips only versioned dependency path fields from detached input
manifests, omits core's path-only widgets dev dependency as Cargo does, and lets
Cargo generate the final archive and normalized manifest. It packages in order
and retains each extracted predecessor in the progressive patch table.

| Package | Payload files | Detached packaging | Normalization comparison |
| --- | ---: | --- | --- |
| API 0.2.1 | 5 | Pass | Equal to the prior current-candidate Cargo-normalized manifest. |
| Core 0.2.7 | 80 | Pass | Equal to the prior current-candidate Cargo-normalized manifest. |
| Platform 0.2.6 | 111 | Pass with extracted API/core | Equal to prior Cargo normalization after the explicit core minimum 0.2.7 and Cargo's new auto-discovered `wayland_model_vectors` test target. |

Platform without the unpublished core patch fails with exit 101 at the exact
`rlvgl-core ^0.2.7` dependency. The same detached input packages with exit zero
when the extracted predecessor is available. This demonstrates the real failure
boundary and proposed progressive resolution, rather than lowering the minimum.
All final dependency tables are free of live sibling paths. After integrating
the platform documentation fixes and test-only session fixture, the experiment
was rerun on the final assembled content; its platform payload includes the new
fixture source (111 payload files, 196 across the three packages). Earlier
attempt logs remain distinct from the integrated run.

The first platform normalization comparison exposed the newly added test target;
that difference is recorded and reconciled explicitly with the source inventory.
No copy-list expansion or suppressed normalization mismatch was adopted. The
manifest comparison is against the stated reference and adjustments; it is not
an independent successful live-workspace platform packaging run at core 0.2.7.

The experiment compares **payload** file sets, excluding four Cargo-generated
members: `Cargo.toml`, `Cargo.toml.orig`, `Cargo.lock` and `.cargo_vcs_info.json`.
The detached input changes its original-manifest provenance and has no original
Git context. Consequently it does not satisfy the draft's complete archive,
source-provenance or normalized-original equivalence requirements. Final adoption
must preserve and prove those generated members rather than silently exclude
them from the production inventory gate.

The bridge source-profile `cargo package --list` also tries to resolve its
unpublished core requirement and fails offline. This run preserves that exact
failure and narrows the experiment to three packages. Earlier bridge archive
packaging succeeded in its separate online diagnostic; this is not a claim of
permanent bridge publication failure. Full bridge workspace inheritance and
source inventory handling remain implementation/proof requirements.
