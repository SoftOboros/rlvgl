# rlvgl v0.1.9 Release Notes

`rlvgl` v0.1.9 is the release where the project starts to look less like a
small set of Rust UI crates and more like a complete embedded UI product
stack. The headline changes are a much more capable `rlvgl-creator` pipeline,
a substantially more complete STM32H747I-DISCO target, and the runtime
infrastructure needed to ship richer applications on top of the core library.

## Short Release Summary

`v0.1.9` adds board-aware BSP generation, expands the workspace with i18n and
chip database crates, and turns STM32H747I-DISCO into a serious showcase target
with display, touch, storage, audio, and accelerated rendering paths.

## Highlights

### Creator and BSP generation

- `rlvgl-creator` now covers more than asset preparation. It can import vendor
  project data, emit a vendor-neutral board IR, and render Rust BSP code from
  templates.
- STM32 BSP generation is now backed by bundled alternate-function databases
  instead of ad hoc per-board tables, making the workflow more portable and
  easier to publish.
- The workspace now includes generated STM BSP crates plus vendor chip
  databases for STM32, Nordic, Espressif, NXP, Silicon Labs, Microchip,
  Renesas, TI, and RP2040 families.

### STM32H747I-DISCO as a flagship platform

- The STM32H747I-DISCO example progressed from board bring-up into a full demo
  platform with dual-core startup, SDRAM, DSI display, touch, SD/MMC storage,
  optional C HAL bindings, and backlight support.
- The demo experience now includes splash handling, settings flows, file
  browsing, system/live stats views, event overlays, and a more intentional app
  layout built on the higher-level UI layer.

### Faster and cleaner rendering

- The rendering pipeline gained `EventWindow` integration, centralized
  compositor/save-under behavior, anti-aliased rounded corners, motion helpers,
  and better dirty-region restoration.
- Hardware acceleration work on DMA2D, LTDC, and ERIF gating improved frame
  pacing and reduced contention on the STM32H747I-DISCO path.
- Recent branch work focused on cache coherency, bank-separated framebuffers,
  scan-aware present timing, and other fixes aimed at reducing flicker, tearing,
  and unnecessary re-rendering.

### Better input, media, and application plumbing

- Input handling now includes multi-touch support, gesture recognition,
  coordinate normalization in the platform layer, and timer-driven touch
  sampling for the Disco board.
- Media support expanded with WAV playback from SD card, MEMS microphone
  capture, and richer demo effects such as the Star Wars crawl pipeline.
- The root crate now exposes a broader workspace that includes UI helpers,
  application/demo crates, and shared API definitions for future bindings and
  coprocessor integrations.

### Localization and publishing readiness

- `rlvgl-i18n` introduces compile-time translation blobs with runtime override
  support, making localization part of the product instead of an afterthought.
- The repo now carries translated documentation sets and publish/CI updates for
  the expanded crate graph, including sequencing for crates.io propagation.
