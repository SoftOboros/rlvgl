## Implemented bounded mechanism

`scripts/crates_ci_package.py` reads actual Cargo inventories and original
manifests. It copies real payload files into detached temporary inputs, admits
only the accepted real path-only dev closure, and routes every predecessor to
its already extracted archive. Cargo owns normalized manifests, temporary graph
locks and archive bytes. The helper rejects missing predecessor routes, unsafe
or missing inventory, unsupported workspace inheritance/descriptors, source
mutation and non-extracted local resolution. Admission paths are renamed away
before extracted-only metadata resolution. Complete generated-member hashes
are recorded separately from payload equality; normalized manifests are not
handwritten. `--no-verify` means these operations do not compile packaged code.

The shell retains its source clean-tree refusal, asset preparation, metadata
warning promotion and existing-version content-drift logic. It removes the
core/bridge patch deferral and adds every extracted predecessor immediately.
The intrinsic dirty sparse input is separate from the outer source cleanliness
gate. Python 3.11+ is required for `tomllib`; local checks used installed Python
3.12, without package/SDK installation.
