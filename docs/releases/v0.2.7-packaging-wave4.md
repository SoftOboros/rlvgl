## Decisive mechanism proposal and preserved stops

The retained-lock failure is resolved for this fixture by separating **real
source graph admission** from **Cargo-normalized extracted-only package
resolution**. The [current Draft 01B](../crates-ci/CRATES-CI-01B-STAGING-ISOLATION.md)
requires every sibling alias to be an already extracted predecessor. This trial
does not satisfy that literal blanket condition: widgets and its closure are
not yet extracted predecessor packages. The governing contract must explicitly
dispose of this narrow admission exception before implementation.

Proposed amendment: permit exact Cargo-listed source copies solely to admit
path-only dev dependencies and their real source graph, retaining original
manifests and recorded hashes. Previously admitted predecessors must still
route only to their extracted archives. Cargo must own normalization; complete
original/normalized manifest, lock and VCS accounting must pass. After archive
creation, remove access to admission paths and prove extracted-only resolution.
Admission copies must never enter a consumer patch table or replace an admitted
predecessor. This is a reviewable proposed mechanism, not a silent relaxation.
