## Packaging blocker

The offline staging attempt stopped at an uncached Ratatui `color-eyre`
dependency. A network-enabled retry passed bridge packaging and stopped at
platform because the existing core/bridge deferral prevents resolution of the
then-selected `rlvgl-core 0.2.6` (subsequently advanced to `0.2.7` by owner
direction). Retaining the extracted core patch produces a live versus
extracted API lockfile collision. Nine selected packages were packaged before
this failure; this is not a green Gate P result.

A new bounded staging diagnostic with core `0.2.7` packaged API `0.2.1`,
core `0.2.7` and bridge `0.1.1`, then failed platform `0.2.6` because its
unpublished core dependency was deferred. This confirms the defect at the
current version; it is partial diagnostic packaging, not Gate P. The initial
offline nested-workspace resolver failure and successful online packaging retry
remain separate records.

The diagnosis and proposed isolated-package correction are in
[the Gate P proposal](v0.2.7-gate-p-proposal.md),
[CRATES-CI-01B](../crates-ci/CRATES-CI-01B-STAGING-ISOLATION.md) and
[ERRATA-001](../crates-ci/ERRATA.md). The amendment is drafted and unratified.
The staging contract and release gate remain enforced.
