# v0.2.7 H747 diagnostic software receipt

both producer/consumer directions, impossible depth rejection, and parsing
mocked probe output. They do not contact a probe.

segments in their respective flash banks, no segment overlap with the legacy
mailbox, identical mailbox symbols, required artifacts, and the CM7 binary

new MPY memory geometry, cache policy, signaling or transport.
