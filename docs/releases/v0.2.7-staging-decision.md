## Result and comparison boundary

**Cargo 1.96.0 exits 101 before creating a core archive.** It attempts to load
the source dev dependency at
`decision-2/core-package-lock/input/widgets/Cargo.toml`, which is intentionally
absent. The cause chain is:

```text
failed to get `rlvgl-widgets` as a dependency of package `rlvgl-core v0.2.7`
failed to load source for dependency `rlvgl-widgets`
failed to read .../input/widgets/Cargo.toml
No such file or directory (os error 2)
```

The seeded package lock remains byte-identical after failure. No archive exists,
so **the requested all-84-member comparison was not performed**; neither complete
inventory nor normalized/original manifest, lock or VCS equivalence is claimed
for this trial. `core-package-lock.log` retains the exact error and
`results.json` records exit, lock hashes, preservation and comparison status.

This result narrows the cause: replacing the whole source workspace lock with
the actual packaged core lock does not avoid path-only dev dependency loading.
It does not establish a general Cargo algorithm or justify a missing-path bypass.
