## Native source API compatibility

`SubscriptionRegistry::subscribe` now receives `&mut StageRegistry`, and
`SubscriptionRegistry::unsubscribe` receives that mutable owner instead of a
bare `StageId`. Standalone callers must supply their owning Stage. The existing
Endpoint `subscribe` call shape is retained, and Endpoint gains coordinated
`unsubscribe` and native subscription-bearing snapshot begin/read/end methods.
Existing Stage-only snapshot methods and record/page types are preserved.

The mechanical caller migration has its own exact-path handoff extension;
repository regression callers retain their native mutation and teardown
increment assertions relative to the post-subscription baseline. It does not
select a wire encoding or Batch/binding integration.

intermediate containers, invalid owner types, or Array indexing, growth and
errors. Existing Python and Rust behavior differs, so implementation behavior
does not supply a unique normative answer. Those cases are stopped for a new
PCDN. The accepted amendment and repair proceed only for pre-existing,
string-keyed Map members using the existing ancestor lookup and in-place owner
mutation. The owning M1P6 document carries the alternatives for owner review;
neither alternative is adopted by this execution record.
