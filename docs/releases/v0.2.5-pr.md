# Pull request: rlvgl v0.2.5 — reactive Qt, SCTD, and Ratatui integration

## Summary

This merges the complete `v0.2.5` release line onto GitHub `main`, compared
from `refs/tags/v0.2.4` (`5187ce0`). The release makes generated Qt/QML screens
reactive against iState state machines, ships the multi-platform SCXML Tutorial
Demo, and adds the first two-way Ratatui ↔ rlvgl integration—Rust all the way
down from generated machine code through terminal cells, widgets, font
rasterization, framebuffer rendering, and the STM32H747I-DISCO display path.

## What changed

- Qt emitter output v14 → v23: sibling-anchor resolution, component
  instantiation, typed predicate/visibility/chained-image bindings, button
  event tables, external-text bindings, and strict-Clippy-clean generated Rust.
- New SCTD app: Setup, interactive/automatic Dining Philosophers, and the
  reactive Škoda Bolero media screen on host simulator, STM32H747I-DISCO,
  UEFI, and ESP32-P4 ESP-IDF hosts.
- New `ratatui-rlvgl` `0.1.0`: a `no_std + alloc` Ratatui backend and an rlvgl
  hosting widget, without C LVGL, FFI, embedded-graphics, or a C toolchain.
- New hybrid Dining Philosophers hero window and deterministic six-frame GIF;
  native and Ratatui presentations share live state and controls.
- Runtime image mutation/visibility APIs, transparent-key asset conversion,
  SCTD tutorial and Qt binding documentation, and Verilog/VHDL/Quartus handoff
  for the five-seat Dining Philosophers demonstration.
- Release infrastructure now stages and publishes the excluded Ratatui
  submodule crate in dependency order immediately after `rlvgl-core`.
